## 🚀 Repositórios e Sistemas em Destaque

👉 **[Portif-lio-engenharia-IA](https://github.com/Celio738/Portif-lio-engenharia-IA)** — Repositório unificado com meus principais projetos de Engenharia de IA, NLP, Dados e Backend:

* 🤖 **[GenAI Delivery Review Triage](https://github.com/Celio738/Portif-lio-engenharia-IA/tree/main/genai-delivery-review-triage):** Pipeline de triagem operacional de avaliações de delivery com **Gemini 2.5 Flash**, contratos estritos via **Pydantic (Structured Outputs)**, sanitização determinística de dados sensíveis (**LGPD / PII Masking**), defesa contra *Prompt Injection* e controle de idempotência em **SQLite**.
* 📝 **[Desafio CAEd — NLP Text Classification](https://github.com/Celio738/Portif-lio-engenharia-IA/tree/main/desafio-caed-nlp):** Pipeline de Processamento de Linguagem Natural em língua portuguesa (pré-processamento NLTK, vetorização TF-IDF e classificação supervisionada com *Random Forest*) para avaliação automatizada de complexidade textual educacional.
* 🔒 **[Desafio TWR — Webhook & Idempotency API](https://github.com/Celio738/Portif-lio-engenharia-IA/tree/main/desafio-twr-postbacks):** API RESTful em **TypeScript, Node.js, Express e SQLite** projetada para recepção de postbacks de vendas, com validação estrita de schema (**Zod**) e garantia de idempotência transacional contra duplicidade de eventos.
* ⚽ **[Brasileirão Analytics & Predictive Valuation](https://github.com/Celio738/Portif-lio-engenharia-IA/tree/main/brasileirao_analytics):** Aplicação analítica em **Python, Streamlit e SQLite** combinada com pesquisa em Aprendizado de Máquina (*XGBoost, LightGBM, Ridge Regression e explicabilidade SHAP*) para modelagem de desempenho esportivo, *Expected Goals* (xG) e valoração de atletas.
